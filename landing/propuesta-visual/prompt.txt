Use case: ui-mockup
Asset type: high-fidelity visual proposal for the desktop landing page of OpenFunnel, an open-source project. Generate ONE polished raster image, a straight-on full-page web design, approximately 1536 x 2560 portrait canvas with desktop-width layout. Not a photograph, no laptop/device mockup, no browser chrome. A coherent single website from header to footer, beautifully typeset, enough whitespace and legible text.

Source concept: OpenFunnel is an open-source platform for building AI-powered business workflows. Sales, Support and Commerce are use cases running on one shared funnel engine. Conversations or entities enter, pass through states, and reach an outcome. Shared primitives: Agent, Conversation, Channel, Contact, Knowledge, Tool, Workflow, Human handoff, Memory, Webhooks, MCP, API. Custom funnels have a name, trigger, stages and agent. The engine and a future ecosystem are the core. This is an early project: no features are production ready, no chosen license yet, no confirmed self-hosting story.

Creative direction: original, refined technical editorial design for a community-built developer product. Warm ivory page, ink-black typography, restrained vivid cobalt blue for primary actions and connector paths. Fine gray rules, subtle engineering dot-grid only within workflow canvas. Modern grotesk sans serif, large confident display heading, small monospaced section labels. Wide whitespace, meticulous alignment, restrained small corner radii. Distinctive flow engine visualization is the main brand device: horizontal thin paths converge through one central engine and branch into three useful outcomes. No decorative stock art, robots, glowing orbs, gradients, giant pill shapes, or generic dashboard card grids.
