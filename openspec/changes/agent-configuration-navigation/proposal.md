# Proposal

## Why
Prompts y tools son configuración de agentes IA y no necesitan entradas independientes en la navegación principal.

## What Changes
- Quitar Prompts y Tools del sidebar en todas sus variantes.
- Añadir navegación interna Agentes / Prompts / Tools dentro de Agentes IA.
- Conservar CRUD, enlaces directos, filtros, confirmación de cambios y asociaciones existentes.
- No cambiar tablas, endpoints ni convertir los catálogos compartidos en copias por agente. Sin decisiones pendientes.

## Capabilities
### New Capabilities
Ninguna.
### Modified Capabilities
- `platform-ui`: agrupación de catálogos bajo Agentes IA.

## Impact
Metadatos de navegación, shell React, CSS y documentación. Sin migraciones ni dependencias nuevas.
